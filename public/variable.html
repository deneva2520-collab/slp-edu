Променливите в Python

Разберете как компютърът "помни" информация. Представете си променливата като кутия с етикет, в която съхраняваме данни за нашата програма.

Започни Опита
01. Концепция

Какво е променлива?

Според урока, променливата е име, което пази стойност. Най-лесният начин да си го представим е като кутия. В Python създаването е лесно: просто пишем името, знака равно, и стойността.

Създай своя променлива:

02. Типове Данни

Скенер за Типове

В Python не е нужно да казвате типа предварително (динамично типизиране). Python сам разбира дали сте въвели число, текст или булева стойност. Тествайте скенера по-долу!

Въведи данни за анализ:

Засечен Тип:
str

Текст (низ). Винаги ограден в кавички.

int 🔢

Цели числа (напр. 5, -10)

float 🔣

Дробни числа (напр. 3.14)

str 🔤

Текст (напр. "Здравей")

bool ✅

Логически (True/False)

История на сканирането

Диаграмата показва разпределението на типовете, които сте тествали.

03. Правила

Валидни ли са имената?

  • ✔ Могат да съдържат букви, цифри и долна черта (_).
  • ✔ Трябва да започват с буква или долна черта.
  • ❌ Не могат да започват с цифра.
  • ❌ Не трябва да съвпадат с команди (напр. print, class).
  • ❌ Без интервали (използвайте _).
❓
Започнете да пишете, за да проверите...
04. Промяна на Стойност

Времева Линия на Стойността

Компютърът изпълнява кода ред по ред. Ако променим стойността на променлива, старата стойност се изтрива и се заменя с новата. Вижте как се променя променливата points (точки) в една игра.

game.py
# Начало
points = 0
# Събрахме бонуси
points = 10
# Още точки
points = 15
# Изчисление (15 + 5)
points = points + 5
# Край на играта (Нулиране)
points = 0

Стойност на 'points' във времето

points = 0
